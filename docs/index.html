稼働状況の見方

トップページとニュースのページを、外部から約5分ごとに確認しています。接続できることとページ本文を確認しており、すべての機能の動作を保証するものではありません。

ガイセンNOWの過去の履歴には、UptimeRobotで計測した記録を引き継いでいます。元の日別稼働率と障害の発生・復旧時刻を照合し、日本時間で集計しています。過去の各チェックの回数は取得できないため表示していません。現在は両方のページが正常な時間を正常稼働として集計し、一方だけの障害も履歴に含めます。

稼働率は、記録が得られた区間の時間から算出する目安です。取得できた履歴のない期間と、新しい監視で確認の間隔が15分を超えた区間は集計に含めません。履歴の「正常」は、その日に確認できた範囲での状態です。

監視の実行や結果の反映が遅れる場合があります。最終確認から20分を超えると、最新の状態を確認できていない旨を表示します。日時は日本時間です。
